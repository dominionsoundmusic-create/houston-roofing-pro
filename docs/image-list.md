# Images to generate in Artistly

Generated by `python3 build.py`. The 12 existing roof photos are used first; every image below already has its final
tag in the page (file name, alt, width, height, lazy loading for in-body images, eager loading
and a preload for heroes). Until the file is saved, the build serves a navy brand-color block
placeholder of the same name and size, so nothing ever shows as broken.

To add a photo: generate it from the prompt, save it as a JPEG under the exact file name and
size in `src/static/images/`, run `python3 build.py` (it makes the WebP sizes), commit.

Style for every image: bright, clearly visible, Houston-area homes and roofs (brick and siding,
ranch and two-story houses, asphalt shingle, metal and flat roofs, live oaks and pines, flat Gulf Coast land),
natural daylight, no text, no logos, no watermarks, no recognizable faces. Every prompt starts
with: wide cinematic landscape shot, subject positioned on right third of frame, well lit.

Total: 18 images (1 heroes at 1920x1080 listed first, then 17 in-body images at 1200x800).
